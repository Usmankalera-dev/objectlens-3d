4 · How it works

  1. Print the marker. A 40 mm ArUco square (marker.png, print at 100%). Check it with a ruler — if your printer scaled it, just tell the scanner the real size.
  2. Measure in one photo. Marker + object in one shot → the marker gives px-per-mm at that plane → the object's box becomes true millimetres.
  3. Rotate & shoot ±12 views. Turn the object ~30° at a time on a plain background. Silhouettes are segmented automatically.
  4. Carve the hull. A 96³ voxel volume keeps only voxels inside every silhouette — the visual hull — exported as a PLY point cloud or mesh.

Run it yourself

python make_marker.py --size-mm 40
python scan.py measure photo.jpg --marker-mm 40
python scan.py hull view_*.png --step 30 --marker-mm 40 --mesh

Honest limitations

  • Single-plane scale: the marker calibrates the plane it sits in. An object much closer to / farther from the camera than the marker will be off by the depth ratio.
  • Silhouettes are approximate: a visual hull can never carve concavities (dents, holes, the inside of a mug) — it is the object's outer shell, not a LiDAR scan.
  • Occlusions & background: parts hidden in a view stay "unknown"; busy or similarly-coloured backgrounds break segmentation. Plain background, good light.
  • Test numbers are synthetic: accuracy above was measured on rendered scenes with exact ground truth, not on a physical product. Real-world error will be larger.
